NeuronTrace

Kernel-Level Behavioral Containment for AI Agents

  • Rust
  • eBPF
  • LSM
  • AI Containment

Overview

Kernel-level behavioral containment for AI agents operating at the syscall layer. NeuronTrace profiles what an agent is *supposed* to do, then fences what it *can* do — intercepting file, network, and process syscalls through eBPF/LSM hooks so a prompt-injected or runaway agent hits a hard kernel boundary, not a hopeful sandbox.

What it does

> profile.agent(policy.yaml)
> fence.syscalls(openat, execve)
> contain.breach_attempt BLOCKED
