Overview

An MCP (Model Context Protocol) server that hands AI agents a full offensive-security workbench. Agents can chain reconnaissance, exploitation, and post-exploitation tools through a standardized interface — turning an LLM into an operator with a real toolkit, and giving defenders a platform to study how agentic offense actually behaves.
