KubeDagger

eBPF Offensive Toolkit for Kubernetes

  • Golang
  • eBPF
  • Kubernetes
  • Container Escape

Overview

An eBPF offensive toolkit built for Kubernetes environments: in-cluster network discovery, process hiding from security agents, and container escape primitives — all running at the kernel level where most runtime defenses cannot see. Designed for red teams validating container hardening and for blue teams understanding their blind spots.

What it does

> net.discover(pod_cidr)
> hide.from(runtime_agent)
> breakout.namespace escape
