Aegis-Shadow

Dual-Module eBPF Rootkit & Runtime Auditor

  • Rust
  • eBPF
  • Linux Kernel
  • Runtime Auditing

Overview

A dual-module eBPF framework that pairs kernel rootkit techniques with their runtime audit counterparts — every hiding primitive ships with the detection that catches it. Built to understand ring-0 offense honestly: process hiding, syscall hijacking, and tracepoint manipulation, each mirrored by a verifier-grade audit hook.

What it does

> bpf.load(aegis_shadow.o)
> ring0.attach(tracepoint)
> audit.mirror(hide_module) OK
